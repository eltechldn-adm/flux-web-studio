How Fixed Pricing Works

During the scoping phase, we define exactly what features will be built. We then quote a single, fixed price for that delivery.

If we take longer to build those features than estimated, we absorb the cost. If you request new features mid-build, we will quote them as a separate phase or swap them for existing scope.

Hosting & Maintenance

Once the software is built, it needs to run somewhere. For simple projects, this can be as low as £0-£20/month via platforms like Cloudflare and Supabase.

We offer optional retainer packages starting at £350/mo for businesses that want us to handle infrastructure, security updates, and minor improvements.
